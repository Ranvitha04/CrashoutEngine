ABOUT THE ENGINE
------------------------------------------------------------
CrashoutsEngine is a lightweight, performance-driven 2D engine
designed for fast iteration, custom gameplay systems, and
tight real-time control. Built with modern C++20, the engine
provides:

 - A real-time component/entity system
 - Custom 2D renderer with batching
 - Integrated audio layer (FMOD)
 - Input, timing, camera, and math utilities
 - Editor and debugging integrations (ImGui)
 - Asset pipelines for textures, fonts, prefabs, and scenes

CrashoutsEngine powers the game “Descent” and is developed with
a focus on clarity, extensibility, and attempt to mimic 
professional production standards.
