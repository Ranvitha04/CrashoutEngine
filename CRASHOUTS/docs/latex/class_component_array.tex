\doxysubsection{Detailed Description}
A templated array for storing a specific type of component. 

This class is the core of the \doxylink{class_e_c_s}{ECS}\textquotesingle{}s data storage. It uses a sparse-\/set data structure to store components of type {\ttfamily T} in a contiguous vector ({\ttfamily dense}). It maintains efficient mappings between entity IDs and component indices, allowing for fast component access and O(1) removals.
