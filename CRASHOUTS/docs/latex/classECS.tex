\doxysubsection{Detailed Description}
The core Entity-\/\+Component-\/\+System (\doxylink{classECS}{ECS}) manager. 

This class serves as the central hub for the \doxylink{classECS}{ECS} framework. It is responsible for creating, destroying, and managing entities and their associated components. It maintains a collection of component arrays, one for each component type, enabling efficient data access and manipulation.
