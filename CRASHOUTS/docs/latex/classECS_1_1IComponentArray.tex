\doxysubsection{Detailed Description}
An abstract interface for component arrays. 

This base class provides a polymorphic way to remove components from an entity without knowing their specific type. This is particularly useful when destroying an entity, as the \doxylink{classECS_1_1ECS}{ECS} can iterate through all component arrays and call a single {\ttfamily Remove\+Component} function for each one.
