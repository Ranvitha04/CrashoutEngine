==================================================
PROJECT SETUP AND BUILD GUIDE
==================================================

Welcome! This guide provides instructions on how to install the necessary tools, generate the project files, and build the application using Windows and Visual Studio 2022.

***
==================================================
PREREQUISITES
==================================================

Before you begin, make sure you have Visual Studio 2022 installed with the "Desktop development with C++" workload.
* You can download it here: https://visualstudio.microsoft.com/downloads/

***
==================================================
STEP 1: INSTALL CMAKE
==================================================

This project uses CMake to generate the Visual Studio project files.

1.  Download CMake:
    * Go to the official download page: https://cmake.org/download/
    * Under the "Binary distributions" section, download the latest "Windows x64 Installer" (.msi file).

2.  Run the Installer:
    * During installation, you will reach an "Install Options" screen.
    * IMPORTANT: You must choose either "Add CMake to the system PATH for all users" or "Add CMake to the system PATH for the current user". This allows the scripts to find and run CMake from the command line.

3.  Verify Installation:
    * After installation, open a new Command Prompt and type "cmake --version". If it prints a version number, you are all set!

***
==================================================
STEP 2: BUILD & RUN THE PROJECT
==================================================

The entire build and run process is automated with a single script.

* To run in 'CrashoutEditor' mode (default):
    * In the project's root folder, type 'CrashoutEdtior' after 'run.bat' 
      to build the editor.

* To run in 'Descent' mode:
    * In the project's root folder, type 'Descent' after 'run.bat' 
      to build the game.

* To run in 'Debug' mode (default):
    * In the project's root folder, simply double-click the "run.bat" file.
    * Solution is found in the x64-Debug folder.

* To run in 'Release' mode:
    * Open a Command Prompt in the root folder.
    * Type "run.bat Release" and press Enter.
    * Solution is found in the x64-Release folder.

* What this script does:
    1.  Creates a "build" folder (if it doesn't exist).
    2.  Runs CMake to configure the project and generate Visual Studio files.
    3.  Builds the project's C++ code (defaulting to 'Debug').
    4.  Automatically launches the "Descent.exe" executable with the correct working directory so it can find its assets.

***
==================================================
STEP 3: CLEANING UP (AND SAVING ASSETS)
==================================================

If you need to delete all generated files and start over, use the "clean.bat" script.

* How to run: Simply double-click the "clean.bat" file.

* What it does:
    1.  Cleans Project: After syncing your assets, it completely deletes the "build" directory.

***

==================================================
STEP 4: DISABLING IMGUI
==================================================

If you need need to test the game without the IMGUI.

* How to run: Simply double-click the "TOP-LEVEL CMAKELISTS.TXT" Then look for "USE_IMGUI_EDITOR"
	      flag and disable it by setting it to 0.

* What it does:
    1.  Tells the program to not use imgui.

***
==================================================
HOW TO DEBUG IN VISUAL STUDIO
==================================================

If you want to use the Visual Studio debugger (e.g., to set breakpoints):

1.  First, run "run.bat" at least once to generate the "build" folder.
2.  Open the "build" folder and double-click the "CRASHOUTS.sln" (or equivalent) solution file.
3.  Once the solution is open in Visual Studio:
    * In the "Solution Explorer" panel, right-click on the "Descent" project.
    * Select "Set as StartUp Project". (Do not set the "CrashoutEngine" library as the startup project).
    * Use the dropdowns at the top to ensure the configuration is set to "Debug" and the platform is "x64".
    * Press F5 or the green "Local Windows Debugger" button to compile and run with the debugger attached.
